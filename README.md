# QR 傳檔

用螢幕上的 QR Code 把檔案從一台不能連網的電腦傳到手機。

- `sender-ie11.html`：傳送端。單一檔案、無外部依賴、純 ES5，可在 IE11 開啟。把檔案切片成標準 QR Code（Version 1～40、容錯 L）輪播。
- `index.html`：接收端。手機瀏覽器開啟，鏡頭對著傳送端畫面，自動依頁碼重組並下載。解碼全在手機本機完成，不上傳任何資料。

## 用法

1. 把 `sender-ie11.html` 存到離線電腦，用瀏覽器開啟，選檔案，按「自動輪播」。
2. 手機開接收頁，按「開始掃描」，對著畫面直到進度條跑滿。
3. 按「下載檔案」。噴泉碼會自動驗證 CRC32；帶頁碼標籤請核對兩邊顯示的 CRC32 相同。

## 格式

- **噴泉碼（預設）**：每張 = 17 位元組檔頭（`QF`、版本、資料流 CRC32、長度、塊大小 K、種子）+ K 位元組資料。資料流 = 檔名長度 + 檔名 + 檔案內容，切成 N 塊；種子小於 N 的張是原文，其餘是隨機挑出的塊 XOR 在一起。接收端做 GF(2) 高斯消去，收到約 N 張（多幾張）就能還原，漏掉哪幾張都沒關係。文字版是 `QF1:` + 整張的 Base64。
- **帶頁碼標籤**：`頁/總頁|檔名|Base64 片段`，缺頁可在傳送端指定補播。
